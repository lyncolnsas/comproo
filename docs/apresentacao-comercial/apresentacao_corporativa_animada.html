Criando Campanhas e Conectando Números

O sistema opera com um pool de 2 a 8 números simultâneos e biblioteca central de mídias para encaminhamento sem re-upload:

https://mikrogestor.com/dashboard/whatsapp (Pool de Instâncias)
https://mikrogestor.com/dashboard/whatsapp/templates (Editor de Campanhas)

Passo 1: Pareamento Seguro via QR Code

Conecte de 2 a 8 números de WhatsApp corporativos. O sistema salva as sessões de forma permanente no banco de dados SQLite persistente, garantindo que os chips continuem logados mesmo após reinicializações do servidor.

Passo 2: Auto-Inclusão no Grupo de Mídias

Ao emparelhar um novo chip, o robô verifica o grupo central (ex: Mikrogestor-FAP-2) e entra automaticamente via código de convite. Você posta os vídeos e banners de ofertas no grupo e o sistema reencaminha aos clientes sem consumir banda de upload!

Passo 3: Distribuição Circular Round-Robin

Cada mensagem disparada para um cliente conectado alterna entre os números disponíveis. Caso um chip fique sem bateria ou perca conexão, o sistema realiza failover imediato para os outros números ativos sem falhar o envio.
